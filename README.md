# Requeter-une-basse-de-donnees-avec-SQL
Requêter une basse de données avec SQL

## Description
Ce projet consiste à manipuler une base de données relationnelle en utilisant le langage SQL. Le but est d’explorer, interroger et extraire des informations pertinentes pour répondre à des besoins métier précis.

## Objectifs
Maîtriser les bases du langage SQL : SELECT, WHERE, JOIN, GROUP BY, ORDER BY, etc.
Construire des requêtes efficaces pour analyser des données commerciales.
Comprendre la structure d’une base de données et les relations entre tables.
Produire des résultats exploitables pour la prise de décision.

## Instructions pour reproduire l’analyse
Importer la base de données fournie dans votre système de gestion de base de données (ex. MySQL, PostgreSQL, SQLite).
Utiliser les scripts SQL fournis dans le dossier /sql pour exécuter les requêtes sur la base.
Adapter ou écrire de nouvelles requêtes selon les questions posées dans le cahier des charges.
Exporter les résultats sous forme de tableaux ou fichiers CSV si besoin.

##Outils utilisés
SGBD SQL au choix (SQL Power Architecte, PostgreSQL).
Outil client SQL ou interface graphique (MySQL Workbench, DBeaver, PgAdmin, etc.).
Éditeur de code pour modifier et sauvegarder les scripts SQL.

## Résultats techniques
Scripts SQL complets et commentés pour chaque requête demandée.
Résultats des requêtes montrant la manipulation des données : filtrage, agrégation, jointures.
Documentation expliquant la logique et l’objectif de chaque requête.
Compétences renforcées en interrogation et gestion de bases de données relationnelles.
